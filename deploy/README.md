# 部署与上线检查

Copyright 2026 上海如静知华信息科技有限公司。

本地体验可复制 `.env.example` 为 `.env`，修改所有密码及 JWT 密钥后执行 `docker compose up --build`。前端默认端口 `8090`，后端默认端口 `8080`。

流程系统上线前至少应完成 HTTPS、密钥托管、数据库备份恢复演练、岗位分离、最小权限、数据范围、金额二次复核、不可篡改审计、日志脱敏、限流和监控告警。若对接银企直联、支付机构、电子发票或税务系统，应另行完成接口签名、证书轮换、回单验真、幂等与对账差错流程。

`.env`、数据库备份、私钥、网银证书、Token、真实银行账户和任何真实流程数据不得提交至仓库。
