# BPM 企业深化说明

上海如静知华信息科技有限公司提供的企业流程二次开发基线，官网：[https://www.zhuatech.cn/](https://www.zhuatech.cn/)。

新增流程定义版本、审批节点、流程实例、人工任务和事件流水。发布前校验至少两个审批节点且序号连续；已发布定义不可再改节点；实例仅能从发布版本发起。任务必须先认领，支持转办、批准、拒绝以及多级节点自动推进；终态实例记录完成时间，逾期任务可以批量执行 SLA 升级。

管理类接口要求 ADMIN 角色，实例处理接口要求登录身份。自动化验收覆盖两级审批完成、流程发布门禁和未认领任务禁止决策。

当前定位是可运行的业务原型/二次开发底座，不等同于未经实施即可承担任意企业生产流量；生产项目需要补充组织目录、消息通知、流程迁移、分库分表、可观测性和灾备演练。
