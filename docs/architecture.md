# BPM 架构

Copyright 2026 上海如静知华信息科技有限公司。

```text
Vue 3 管理端 / 移动审批 H5
             │ REST + JWT
             ▼
Spring Security ─ Controller ─ BPM Service
                                  │
       ┌────────────┬─────────────┼───────────┐
       ▼            ▼             ▼           ▼
   流程模型       流程实例       任务队列      SLA 策略
       └────────────┴──── MySQL / Flyway ──────┘
```

社区版采用模块化单体，便于个人理解和二次开发。领域边界包括模型版本、实例状态、任务分配、审批办理和 SLA 统计。企业扩展可接入 BPMN 引擎、消息总线、组织中心、电子签章、归档系统和统一审计平台。
